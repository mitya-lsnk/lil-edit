# Changelog

Версии показаны в приложении: на главном экране под логотипом (`Image Toolkit · vX.Y.Z`)
и в «Настройки → О программе».

## Unreleased

- **Новая иконка**: фиолетовый лис со значком кропа (на чёрном) — на всех платформах.
- **Тост сохранения**: текст «Сохранено / имя файла» больше не пропадает — раньше длинные
  кнопки («Открыть папку» + «Очистить и начать заново») сжимали блок с текстом в ноль. Теперь
  у текста есть гарантированная ширина, а кнопки при нехватке места переносятся на строку ниже.

## 0.1.4 — 2026-07-26

### Обновления
- **Проверка обновлений**: приложение тихо проверяет последний релиз на GitHub при запуске —
  если есть новее, на «шестерёнке» появляется точка, а в «Настройки → О программе» — карточка
  с версией, списком изменений и кнопкой «Скачать» (прямая ссылка на .dmg, иначе страница
  релиза). Плюс кнопка «Проверить обновление» вручную. Ничего не ставится само — установку
  делает пользователь (сборка без подписи).

### Новые инструменты и функции
- **Редактор изображений**: кроп с шаблонами, поворот/отражение, ресайз в px/%, undo/redo.
- **Пакетная обработка (Batch)**: апскейл / удаление фона / сжатие / ресайз для целой папки.
  - Пути «источник» и «назначение» всегда доступны для выбора; галочка «Запомнить»
    сохраняет их между запусками.
- **Remove BG → раздел «Край»**: жёсткость, расширить/сузить, растушёвка — живая
  постобработка маски без повторного запуска модели; подсказки при наведении.
- **Подложка (фон превью)** во всех инструментах и до обработки: 4 варианта (цвет темы /
  шахматка / белый / чёрный) в Апскейле, Сжатии, Remove BG и Правке — на одиночном превью
  до запуска и в Сравнении после. Выбор реально меняет фон.
- **Отмена загрузки модели** с удалением недокачанных временных файлов.

### Интерфейс и темы
- **Размеры контролов приведены к единой системе по функции**: общие токены `--ctl-h`
  (поля/кнопки в панелях инструментов) и `--ctl-h-head` (шапка) — во всех темах кнопки,
  поля и сегменты одной роли одной высоты, а не «каждая тема по-своему».
- **Кроп (брутализм)**: кнопки панели больше не обрезаются ни в одной теме — вложенные
  чипы тянутся на высоту контейнера, а не задают вторую фикс-высоту поверх толстой рамки.
- **Контраст в тёмных темах**: убран «жёлтый на белом» — бейджи/чипы/инлайн-`code` на
  всегда-тёмной подложке; активные сегменты — акцентным чипом; предупреждение об удалении — красным.
- **Ползунки** стилизованы под тему (заливка в акцентном цвете, обводка, «ручка»).
- **Сравнение**: слайдер теперь первый в списке режимов; «Результат» → «Зажать».
- **Апскейл**: единая высота кнопок/полей; рядом с весом показывается итоговое разрешение
  (например, 4212×6400).
- **Сжатие**: ползунок качества справа от форматов, заголовки выровнены.
- **Лупа**: плавающая кнопка в левом нижнем углу превью, по умолчанию выключена; под
  прозрачным вырезом — шахматка, а не белый фон.
- Скины, модели, светлая/тёмная тема вынесены в «Настройки»/шапку; версия — в «О программе».
- Карточки на главной крупнее на широких экранах; надёжное центрирование иконок.

### Модели и стабильность
- **Не теряем прогресс**: «Назад»/лого/заход в Настройки больше не выбрасывают работу —
  инструмент остаётся живым, на главной появляется «Продолжить».
- **FAQ**: раздел «Какие типы моделей поддерживаются» (ONNX для удаления фона,
  ncnn-vulkan для апскейла); открывается сверху.
