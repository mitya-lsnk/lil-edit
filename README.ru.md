# lil image

[English](README.md) · **Русский**

Кроссплатформенное десктоп-приложение для работы с изображениями: **сжатие**,
**удаление фона** и **апскейл**. Всё считается локально, офлайн — ничего не
уходит в сеть.

## Что уже работает

| Функция | Статус | Движок |
|---|---|---|
| **Сжатие** | ✅ готово, проверено | jSquash (WASM): MozJPEG, WebP, AVIF, OxiPNG |
| **Правка** | ✅ готово | Кроп (шаблоны пропорций), размер (px/%), поворот/отражение — на canvas, без моделей |
| **Пакет** | ✅ готово | Одна операция над целой папкой (апскейл / фон / сжатие / размер), прогресс + папка назначения |
| **Менеджер моделей** | ✅ готово | Скачивание с прогрессом + распаковка, в Rust |
| **Удаление фона** | ✅ реализовано | ONNX (BiRefNet / U²-Net / IS-Net / Silueta) через `ort` |
| **Апскейл** | ✅ реализовано | Три ncnn-vulkan движка: Upscayl, Real-ESRGAN, waifu2x |
| **Язык интерфейса** | ✅ готово | Русский / English, переключается в приложении |
| **Темы** | ✅ готово | Три скина × светлая/тёмная |

> Сжатие протестировано end-to-end в реальном фронтенде (3.3 МБ → 20–48 КБ на всех
> четырёх кодеках). Удаление фона проверено интеграционным тестом на настоящих весах
> u2netp. Апскейл и полный UI-путь фона стоит прогнать вручную (см. ниже) — они требуют
> скачивания моделей на 4–170 МБ.

## Язык интерфейса

Интерфейс есть на **русском и английском**. При первом запуске язык берётся из
локали ОС (русская система → русский, иначе английский), дальше решает
**переключатель RU/EN** в шапке, и выбор запоминается. Весь текст интерфейса
лежит в [`src/lib/strings.tsx`](src/lib/strings.tsx) — добавьте ключ в объект `ru`,
и компилятор потребует парный `en`.

## Стек

- **Tauri 2** — каркас (Rust-бэкенд + системный WebView). Лёгкий, ~10 МБ рантайма.
- **React + TypeScript + Vite** — фронтенд.
- **jSquash** — WASM-кодеки сжатия (те же, что в Squoosh).
- **ort** (onnxruntime) — ONNX-рантайм для удаления фона.
- **ncnn-vulkan движки** — GPU-апскейл через Vulkan, скачиваются менеджером моделей.

## Запуск

Нужны Node ≥ 20 и Rust.

```bash
npm install          # если ещё не ставили
npm run tauri dev    # запустить приложение в дев-режиме
```

Сборка релиза `.app` / `.dmg` / `.exe`:

```bash
npm run tauri build
```

Сборка под macOS появляется в `src-tauri/target/release/bundle/` — `macos/lil image.app`
и `.dmg`. Перетащите `.app` в `/Applications` и запускайте из Launchpad или Spotlight,
как любое приложение: без терминала, дев-сервера и занятого порта.

> `npm run dev` открывает фронтенд в обычном браузере. Сжатие там работает, но
> удаление фона и апскейл требуют Rust-бэкенда, а «сохранить рядом с оригиналом»
> требует нативного пути к файлу — и то и другое есть только в сборке Tauri.

## Как проверить вручную

1. **Сжатие** (без скачиваний): перетащите фото, выберите формат, подвигайте качество,
   «Сжать», сравните до/после, «Сохранить».
2. **Удаление фона**: скачайте **U²-Net (lite)** (4.4 МБ, быстрая проба) или
   **IS-Net (general)** (лучше для портретов), выберите модель, «Удалить фон».
   Результат — PNG с прозрачностью.
3. **Апскейл**: скачайте движок (Upscayl ~115 МБ, Real-ESRGAN ~49 МБ, waifu2x ~35 МБ).
   Поставите несколько — появится переключатель движков. Выберите модель и масштаб,
   «Увеличить». У waifu2x есть ручка шумодава.
   - Нюанс macOS: если Gatekeeper заблокирует скачанный бинарник, приложение уже
     пытается снять карантин (`xattr`); при ошибке разрешите запуск в
     Системных настройках → Конфиденциальность и безопасность.

## Модели (реестр)

Реестр задаётся в [`src-tauri/src/models.rs`](src-tauri/src/models.rs). Все ссылки
прямые и проверены 2026-07-19.

**Фон (ONNX):**
- U²-Net lite — `u2netp.onnx` (4.4 МБ) — https://github.com/danielgatis/rembg
- U²-Net full — `u2net.onnx` (168 МБ)
- IS-Net general — `isnet-general-use.onnx` (170 МБ)
- Silueta — `silueta.onnx` (42 МБ)

**Апскейл (ncnn, архив под каждую ОС выбирается на этапе компиляции):**
- Upscayl — бинарник (сборка 2025-12) + 5 моделей — ~115 МБ — https://github.com/upscayl/upscayl-ncnn
- Real-ESRGAN ncnn-vulkan — 45–49 МБ — https://github.com/xinntao/Real-ESRGAN
- waifu2x-ncnn-vulkan (сборка 2025-09) — 35–42 МБ — https://github.com/nihui/waifu2x-ncnn-vulkan

По умолчанию модели кладутся в `<app_data_dir>/models`
(macOS: `~/Library/Application Support/com.lil.image/models`). Папку можно
переназначить: **Настройки → Хранилище моделей → Выбрать папку…**, галочка
«переносить уже скачанное» перевозит файлы (через copy+delete, так что смена диска
работает).

Добавить модель — допишите запись в `REGISTRY` в `models.rs` (id, url, размер, категория).

## Что дальше / ограничения

- **Передача байтов по IPC** для фона/апскейла идёт массивом чисел — неэффективно для
  очень больших изображений. Позже: временный файл или raw-IPC.
- **Сжатие на главном потоке** — для больших AVIF UI может подтормаживать. Позже: Web Worker.
- Батч-обработка, пресеты экспорта — пока не сделаны.
